# $MSV — Maximising Shareholder Value

A plain-English stock/ETF/crypto research dashboard: search any ticker
for valuation, technicals, financials, and SEC filings — every number
comes with a tooltip explaining what it actually means.

- **[msv-web](https://github.com/Maximising-Shareholder-Value/msv-web)** — the frontend (plain HTML/CSS/JS, no build step)
- **[msv-api](https://github.com/Maximising-Shareholder-Value/msv-api)** — the backend (a Cloudflare Worker proxying Finnhub/Twelve Data/FRED/CoinGecko)

**Live**: [msv-web.jozsua-heng.workers.dev](https://msv-web.jozsua-heng.workers.dev)

Contributions welcome — see either repo's `CONTRIBUTING.md` to get started.
